# Link sheet (fill after pushing to Git hosting and sharing the documents)

Use these values in the class Google Sheets tracker (Activity 3 row and the Activity 4/5/6 Log tabs).

| Tracker column | Value |
|---|---|
| Repository URL (access type) | `https://github.com/<org-or-user>/<repo>`  (public / private with all groups invited) |
| Branch/tag to test | `main` (or release tag `v1.0-activity3`) |
| User roles document link | `https://github.com/<org-or-user>/<repo>/blob/main/docs/user-roles.md`  (or the shared online copy) |
| Progress document (PDF) link | `https://github.com/<org-or-user>/<repo>/blob/main/docs/progress/BinarySisters_Progress_Documentation.pdf`  (or a Drive link set to "anyone with the link can view") |
| Access-control folder link (Act. 4) | `.../tree/main/db-access-control/group-XX` |
| Evidence folder link (Act. 5) | `.../tree/main/db-maintenance/group-XX` |
| Evidence folder link (Act. 6) | `.../tree/main/db-backup-recovery/group-XX` |
